# Village

Тестовая локация деревни, сделанная в Unity как задание для геймдизайнера.

## Описание

Проект представляет собой небольшой уровень с деревней, окружённой лесом.  
На сцене:

- Деревня с домами, расставленными как placeholders под будущий финальный арт
- Лес по периметру, визуально ограничивающий границы локации
- Вход на локацию с одной стороны (дорога из леса)
- Выход с локации с другой стороны, чтобы игрок проходил через деревню

Задача была показать планировку, читаемость путей и зонирование, а не финальное визуальное качество.
